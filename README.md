Разработка фильтрации с помощью ChatGPT

Для создания системы фильтрации на сайте мы использовали ChatGPT. Сначала объяснили нейросети, как должны работать фильтры и что именно они должны делать. На основе наших запросов ChatGPT помог написать необходимый код и встроить его в сайт.
Конечно, не все получилось с первого раза. В процессе тестирования возникали ошибки, поэтому приходилось возвращаться к ChatGPT, объяснять, что работает неправильно, и вместе искать решение.
В итоге нам удалось реализовать нужную функциональность, а использование нейросети заметно упростило процесс нашей разработки
